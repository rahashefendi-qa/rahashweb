# موقع رهش أفندي (Rahash Efendi)

موقع تعريفي فاخر لبيت الرهش والحلقوم "رهش أفندي" — ميناء الدوحة القديم، قطر.

## طريقة المعاينة
- **الأسهل:** افتح ملف `index.html` مباشرة بالمتصفح (دبل كليك عليه).
- أو شغّل أي سيرفر ستاتيك بسيط من داخل مجلد الموقع، مثلاً:
  ```bash
  npx serve .
  ```

## هيكل الملفات
```
rahashweb/
├── index.html          الصفحة الرئيسية (كل المحتوى والأقسام)
├── css/style.css        كل التنسيقات (الألوان، الخطوط، الحركات)
├── js/main.js            بيانات المنتجات + التفاعلات (الفلترة، القائمة، الأنيميشن)
└── assets/images/        مجلد الصور — اقرأ README.md بداخله
```

## الهوية البصرية
- **الألوان:** عنابي `#6B1F2A`، بيج `#F3ECDF`، وردي دافئ `#E3B7B0`، ذهبي `#B8935A`
- **الخطوط:** Aref Ruqaa (عناوين عربية)، Cairo (نصوص عربية)، Cormorant Garamond / Jost (إنجليزي)
- **الشعار:** ختم دائري CSS/SVG قابل لإعادة الاستخدام — إذا توفر لديكم ملف الشعار الرسمي (PNG/SVG)، استبدلوا عنصر `.seal-*` بـ `<img>` يشير له.

## إضافة الصور الحقيقية
كل بطاقة منتج تعرض حاليًا اسم المنتج على خلفية متدرجة أنيقة بدل الصورة.
بمجرد إضافة صورة بنفس الاسم بالضبط داخل `assets/images/` (راجع `assets/images/README.md` للأسماء الكاملة)، تظهر تلقائيًا — بدون أي تعديل بالكود.

## المنتجات والأسعار
البيانات في `js/main.js` (متغيّر `PRODUCTS`) مأخوذة من متجر رهش أفندي الفعلي على سنونو.
لتعديل اسم منتج، وصفه، سعره، أو فئته — عدّل القيم مباشرة في هذا الملف.

## الخطوات القادمة المقترحة
1. إضافة الصور الحقيقية للمنتجات وشعار الدار الرسمي.
2. ربط دومين خاص واستضافة الموقع (Netlify / Vercel / أي استضافة ستاتيك).
3. إضافة نسخة إنجليزية إذا رغبتم بجمهور ثنائي اللغة بشكل كامل.
